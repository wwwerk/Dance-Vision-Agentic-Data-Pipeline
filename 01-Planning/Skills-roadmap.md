# Skills roadmap

## Core engineering

- Python packaging, typing, Pydantic v2, pytest, logging
- Git branches, pull requests, code review, CI
- Docker, Docker Compose, container image pinning
- Linux VPS administration, SSH, secrets, backups
- Parquet, DuckDB, JSONL, data validation

## Video and computer vision

- FFprobe and FFmpeg
- Person detection, 2D pose estimation, tracking, ReID
- MMPose and model/configuration management
- Occlusion and temporal consistency analysis
- COCO keypoints and temporal track metadata
- CVAT import/export and annotation QA

## Agentic systems

- Aider, Continue, Roo Code, or OpenHands workflow
- LiteLLM or provider-routing abstraction
- PydanticAI structured outputs and typed tools
- Prefect workflows, retries, caching, scheduling, artifacts
- LangGraph state, approvals, and durable human-in-the-loop flows

## Evidence of learning

For every major capability, capture:

- What was built
- What failed first
- How it was tested
- What changed after agent assistance
- What safety or quality constraint was added
- How the work appears in the final case study
