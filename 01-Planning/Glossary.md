# Glossary

## Annotation

Human-created or human-reviewed labels attached to video frames, persons, joints, tracks, or events.

## B2

Backblaze B2 object storage. This project treats it as the durable storage layer for raw masters and versioned derived artifacts.

## Clip manifest

A structured record identifying a time interval from a source recording, its derivative files, metadata, rights status, processing status, and output lineage.

## Gold set

A small, carefully reviewed benchmark subset used for evaluation and high-quality training.

## Human-in-the-loop

A design where an automated system pauses for a person to approve, reject, correct, or adjudicate consequential decisions.

## Identity switch

A tracking failure where one person’s persistent track ID is incorrectly assigned to another person.

## Occlusion

A body or keypoint is blocked from view by the person themself, another person, or an object.

## Prelabel

A model-generated initial prediction provided to an annotator for correction. It is not ground truth.

## Run manifest

A machine-readable record of inputs, code version, model version, configuration, hardware, timestamps, outputs, and cost for a pipeline execution.
