# T001.4 Install & Test litellm-proxy Docker Image

## Outcome

Produce a running image of litellm-proxy connecting to one or more frontier model APIs

## Procedure


### Step 1: Create the Project Directory and Config

### Step 2: config.yaml

model_list:
  - model_name: gpt-4o
    litellm_params:
      model: openai/gpt-4o
      api_key: os.environ/OPENAI_API_KEY

### Step 3: Environment Vars

.env

OPENAI_API_KEY=your_actual_openai_api_key_here
LITELLM_MASTER_KEY=sk-12345
DATABASE_URL=postgresql://litellm:password@db:5432/litellm_db

### Step 4: Create Docker Compose Manifest

version: '3.8'

services:
  litellm:
    image: ghcr.io/berriai/litellm:main
    container_name: litellm-proxy
    restart: always
    ports:
      - "4000:4000"
    volumes:
      - ./config.yaml:/app/config.yaml
    environment:
      - DATABASE_URL=postgresql://litellm:password@db:5432/litellm_db
      - LITELLM_MASTER_KEY=sk-12345
      - STORE_MODEL_IN_DB=True
    command: ["--config", "/app/config.yaml", "--port", "4000"]
    depends_on:
      - db

  db:
    image: postgres:15-alpine
    container_name: litellm-db
    restart: always
    environment:
      POSTGRES_USER: litellm
      POSTGRES_PASSWORD: password
      POSTGRES_DB: litellm_db
    volumes:
      - postgres_data:/var/lib/postgresql/data

volumes:
  postgres_data:

### Step 5: Start the proxy
sudo docker compose up -d

### Step 6: Test interface
port: 4000


### Troubleshoot:

Is Container Running?

sudo docker compose ps

Review log, check for restarting or down:

sudo docker compose logs litellm

Restart:
sudo docker compose down && sudo docker compose up -d
