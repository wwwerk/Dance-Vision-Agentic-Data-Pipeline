# Rights and consent policy

## Rule

No source footage is used for model training, external processing, sharing, or publication unless its applicable rights and consent status have been recorded and reviewed for that purpose.

## Separate permissions to track

- Ownership or license to use source footage
- Performer appearance release
- Permission for internal ML/data processing
- Permission for commercial ML/data processing
- Permission for public dataset release
- Permission for distribution of original footage
- Permission for distribution of derivatives such as skeleton data, crops, or embeddings
- Restrictions related to workshop privacy, health/yoga instruction, intimate contact work, minors, or bystanders

## Operational categories

| Status | Meaning | Allowed use |
|---|---|---|
| Cleared internal | Use for private pipeline experiments | Internal processing only |
| Cleared public | Use and publish under defined license | Approved public release only |
| Review required | Insufficient documentation | No processing beyond cataloging |
| Restricted | Known use limitations | Follow written restrictions |
| Excluded | Do not use | No pipeline processing |

## Required record fields

- Source session ID
- Rights holder
- Performer release status
- ML-training permission
- Public-release permission
- Commercial-use permission
- Withdrawal contact/process
- Restrictions
- Review date and reviewer
