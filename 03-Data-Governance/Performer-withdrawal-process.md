# Performer withdrawal process

## Goal

Maintain a documented route for a performer or rights holder to request review, restriction, or removal of eligible material.

## Required capabilities

- Identify source session and related derivatives through lineage records.
- Record request date, requester identity/authority, scope, and action taken.
- Freeze further processing while the request is reviewed.
- Remove or restrict future access when required by agreement or policy.
- Update public documentation if a released subset changes.

## Workflow

1. Receive and authenticate request.
2. Locate source/session and all derived artifacts using manifests.
3. Determine applicable rights and prior release terms.
4. Freeze pending jobs and publication actions.
5. Remove, restrict, or document decision.
6. Record the decision and update dataset version/changelog.
