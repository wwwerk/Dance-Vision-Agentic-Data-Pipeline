# Data classification

| Class | Examples | Storage/access rule |
|---|---|---|
| Restricted raw | Original masters, private workshops, unreviewed performer footage | Private B2 prefix; least-privilege access |
| Internal derivative | Proxies, clips, model outputs from internal-only source | Restricted project prefix |
| Reviewed annotation | Human-reviewed labels attached to restricted source | Restricted; versioned |
| Public-safe derivative | Cleared skeleton renders, synthetic fixtures, anonymized aggregate metrics | Public repository or approved dataset host |
| Public documentation | Schemas, code, runbooks, dataset cards, architecture diagrams | Public after secret review |
