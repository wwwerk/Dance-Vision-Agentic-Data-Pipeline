# Demo script

## Target length

3–5 minutes

## Structure

1. Problem: dense dance/contact video is difficult for pose/tracking systems.
2. Archive and governance: source material stays in B2; rights and privacy are tracked.
3. Pipeline: selected clip → proxy → GPU pose/tracking → artifacts → CVAT review.
4. Agentic workflow: agent proposes a bounded batch; validators and human approval control spending and sensitive operations.
5. Results: show approved overlays, failure flags, annotation improvements, and actual cost/runtime where available.
6. Engineering: manifests, tests, versioned outputs, and reproducible flows.
7. Next step: gold dataset and held-out benchmark evaluation.

## Visual substitutions for restricted video

- Skeleton overlays without original footage
- Blurred or cropped footage
- Synthetic fixtures
- Diagrams and run dashboards
- Aggregate metrics and data-flow diagrams
